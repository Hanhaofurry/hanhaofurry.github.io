# hanhaofurry.github.io# Hanhao English Studio

這是 `hanhaofurry.github.io` 的高中英文教師平台第一版。網站使用純 HTML、CSS 與 JavaScript，可免費部署在 GitHub Pages，也能在 GitHub 網頁中直接維護。

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網站架構、教學文案與既有「英語闖關站」入口。 |
| `styles.css` | 閱讀友善的視覺樣式與行動版版面。 |
| `app.js` | 文法暖身題回饋，以及教材資源搜尋／篩選。 |

## 先改這些地方

請先在 `index.html` 將 `HANHAO`、老師介紹、聯絡信箱 `your-email@example.com` 換成你的真實資料。接著在 `app.js` 最上方的 `resources` 陣列新增自己的閱讀任務、簡報、學習單或課堂活動。現有「英語闖關站」連結為 `https://engquizarc-d5xtnrwu.manus.space`，可保留作為學生自學入口。

每次在 GitHub 按 **Commit changes** 後，GitHub Pages 通常會在數分鐘內更新。第一版不會收集學生帳號、成績或個人資料；既有闖關站的紀錄則依其本站機制處理。
